## 0. 日历视图（0.3.0 新增）—— 请重点验收

准备：日历需要笔记带日期。demo 里的 `01-normal`、`02-crlf-bom`、`04-all-types` 都有 `date`；用 `--count 200` 生成的那批也有各种日期，够用。

| # | 操作 | 预期结果 |
| --- | --- | --- |
| C1 | 视图切换器 →「＋ 新建日历视图」，取名 `发布日历` | 切到一个**月历**界面：顶部有 `‹ 今天 ›`、`2026 年 X 月`，右侧有「日期字段」下拉 |
| C2 | 看月历格子 | 有日期的笔记出现在对应日期格子里、显示标题；没有日期的**不进网格**，但顶部显示「另有 N 项没有日期」 |
| C3 | 点某张卡片 | 在新标签页打开那个 markdown 文件 |
| C4 | 把一张卡片**拖到另一天** | 拖动时目标格高亮；松手后卡片**立刻**到新日期（不用刷新），且文件里的日期字段真的被改了（打开文件确认，其他字节一个没动） |
| C5 | 拖完执行 `MatterTable: 撤销上一次改动` | 文件日期回到拖动前，卡片也回到原来那天 |
| C6 | 点 `‹` / `›` / 「今天」 | 前后翻月，标题跟着变；「今天」回到本月 |
| C7 | 切换「日期字段」下拉 | 若有第二个日期字段（可在配置里给某字段写 `"type": "date"`），切过去后按新字段重新归类 |
| C8 | 给日历视图加筛选条件 | 例如「状态 等于 finished」——日历上只剩匹配的笔记 |
| C9 | 把筛选条件设成让结果全都没有日期 | 月历是空的，但顶部有说明「当前筛选结果里没有任何笔记填写了日期」，而不是一片空白 |
| C10 | 看工具栏 | 日历视图下自动隐藏「字段」列管理、「显示无 front matter 的文件」、表格行数统计；视图切换器与「配置」仍在 |
| C11 | 打开 `.mattertable/config.json` | 能看到该视图 `"type": "calendar"` 与 `"dateField": "date"`；手改 `dateField` 保存，日历自动换字段 |
| C12 | 在配置里给另一个字段写 `"type": "date"`（例如 `updated_at`）后重开表格 | 它出现在日历的「日期字段」下拉里，可以选它归类（这就是「不硬编码 date」） |

**最容易出问题的两处，请重点看**：C4（拖拽是否立刻生效 + 文件是否只改了日期那一段）、C8~C9（筛选与日历的配合）。

**明确不做**：多日任务（start + due 显示成一条跨天条）——按你的要求不做。

## 2. 0.2.1 修好了什么（上一轮反馈）

| # | 你反馈的问题 | 根因 | 修法 |
| --- | --- | --- | --- |
| 1 | 点「添加条件」选完字段后看不见「等于/不等于」等选项，**必须刷新才出现** | 我把筛选条件只发给了宿主机持久化，而宿主机为了不打断输入**故意不回传数据**，于是界面自己一直没更新——所有筛选操作都要等下次刷新（宿主机重发全量数据）才生效 | 筛选条件改成**界面自己先更新、再发给宿主机持久化**（与列显隐、排序、列宽一致的做法） |
| 2 | 点「清除」也要刷新才生效 | 同 #1 | 同 #1 |
| 3 | 操作符下拉里的「等于/不等于/包含…」**白底白字**，不 hover 看不见 | 原生 `<select>` 展开后的选项列表由浏览器/系统绘制，不受原来那几条 CSS 影响；深色主题下就变成白底 + 白字 | 给 webview 的 `body` 加上跟随编辑器主题的 `color-scheme`，并显式给 `option` 指定下拉配色（两条保险） |

**顺便改了消息提示的展示方式**（你提的体验问题）：从「顶部提示条 + 手动点叉」改成**右下角浮层 toast**——不再挤占表格布局（表格不会因为一条消息往下跳），提示类 4 秒、警告类 8 秒自动淡出，错误消息留着等你关闭，相同内容不重复弹。

## 4. 装进 Cursor（先卸旧版再装新版）

因为扩展 ID 没变（`BornfreeYan.mattertable`），装新版前请先卸载旧版，否则可能仍然加载旧的那份。

**卸载旧版**：`Ctrl+Shift+X` 打开扩展面板 → 搜索 `MatterTable` → 卸载；或命令行 `cursor --uninstall-extension BornfreeYan.mattertable`。

**然后三选一安装新版**：

**方式一：图形界面（最省事）**

1. Cursor 里按 `Ctrl+Shift+P`
2. 输入 `Install from VSIX`，选 `Extensions: Install from VSIX...`
3. 选中 `release\mattertable-0.3.0.vsix`
4. 右下角会提示安装成功，点 `Reload`（或手动 `Ctrl+Shift+P` → `Developer: Reload Window`）

**方式二：命令行**

```bash
cursor --install-extension "D:\KnowledgeBase\5 Projects\MatterTable\release\mattertable-0.3.0.vsix"
```

（如果提示 `cursor` 不是命令，用方式一或方式三。）

**方式三：拖拽** —— 把 `.vsix` 文件直接拖进 Cursor 窗口。

**验证版本**：`Ctrl+Shift+X` 搜索 MatterTable，版本应显示 `0.3.0`。

**以后想卸载**：扩展面板里找到 MatterTable → 卸载；或 `cursor --uninstall-extension BornfreeYan.mattertable`。

## 9. 已知行为（属于设计如此，不用当 bug 报）

1. **带引号的日期会被统一成不带引号**：原文 `date: '2026-03-07'`，你在表格里改过这个单元格之后会写成 `date: 2026-03-07`。没动过的单元格不会被改。
2. **空字符串会变成空值**：原文 `date: ""` 或 `categories:` + 空列表项 `- `，在你改这个单元格时会写成 `date:` / `categories: []`。审计显示全库有 45 处属于这类清理，**只有你手动改那些单元格时才会发生**。
3. **多行块标量编辑后会变成单行**：`description: |-` + 缩进的正文，编辑后会变成一行带引号的字符串。不编辑就完全不动。
4. **列表块内部的行内注释会被上移到字段行**：`state:` 下面某一项的 `# 注释`，改这个列表后会跑到 `state: # 注释` 后面（内容不丢，只是位置变了）。
5. **`Tab` 只在本行内左右移动**，不会跳到下一行。
6. **不做**从 Excel / 飞书粘贴导入（你明确说过不要）。
7. **这一版没有**：筛选、多视图、日历视图、批量改多行、在表格里新建/删除文件。这些是 v2。
8. 嵌套结构字段（`hero` / `sitemap` 等）**只读且默认隐藏**，不会也不能在表格里编辑。
9. **日历视图只显示有日期的笔记**：日期字段为空的笔记不进网格（顶部会用「另有 N 项没有日期」告诉你数量）；筛选之后全都没有日期时会显示说明而不是空白。
10. **日历卡片上的文字取 `title` 字段**，没有 `title` 就用文件名（去掉 `.md`）。卡片上不能改标题等其他字段，要改用表格视图。
11. **拖拽改日期会把值规范成 `YYYY-MM-DD`**：如果原字段是 `2026-01-28T03:08:15` 这种带时间的写法，拖一次之后会变成 `2026-01-28`。这是预期行为（日期字段本来就该只存日期）。
12. **不做多日任务**：`start` + `due` 两个字段显示成一条跨天条这种，明确不做。

## 12. 历史修复记录（0.1.1 / 0.1.2，已全部复测通过）

你第一轮反馈的问题全部定位到根因并修掉了。**根因只有两个，但症状很多**：

1. **文本 / 数字 / 日期列整列空白**（你截图里「标题」「日期」看不到内容）：单元格的展示逻辑先判断「标签数组为空就渲染空内容」，而文本类字段的标签数组永远是空的，值被整个吞掉了。
2. **列错位、单元格被压成一个小框**：非编辑态多包了一层 div，内层单元格没有拿到列宽，所以被压成内容宽（空内容 = 0 宽）。
3. **多选弹窗出现在页面左上角**：进入编辑时单元格 DOM 被替换，代码里存着的是**已被替换掉的旧元素**，取坐标得到全 0，于是飘到左上角。
4. **多选里没法输入新标签**：每新增一个标签，宿主会**整表重载**，把你还没提交的标签冲掉。单选之所以正常，是因为单选是「回车即写盘」，写盘先于重载完成。
5. 顺带修掉的体验问题：点列头排序不再重置滚动位置和选中状态；「重置所有列宽」不再整表重载；数字列输入非数字会明确提示（原来用 `type=number`，浏览器会静默吞掉字母，什么反馈都没有）。
6. 交互改成电子表格习惯：**单击只选中（单元格出现高亮框），再单击一次（或双击 / 回车 / F2）才进入编辑**。原来单击直接进编辑，导致「选中后按 Delete 清空」这条路径根本走不到——你反馈的 B7 没法选中就是这个原因。
